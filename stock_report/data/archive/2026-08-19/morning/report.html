教训　本期有三条教训。第一条关于情景与叙事的分离，是上一期的直接错误；第二条关于数据口径，是本期在核对过程中发现的、影响本报过去多期的系统性问题；第三条关于一次做对的事，同样记录下来以便复用。 【教训一：条件命中不等于方向命中——一个区间型情景被讲成了单向叙事】 上一期 base 情景的五项条件，其设计意图在条件②的注释里写得很清楚：「本条按R9写为『或』，以同时容纳『放量后的高位整固』与『获利了结但不破位』两个象限」。也就是说，base 从一开始就是一个区间，它的条件既能被上涨满足，也能被下跌满足。8/18的实际结果是：base 五项条件5/5全部命中，而观察池39/50下跌、均值-1.422%、主线整体切走。条件全对，方向全错。 问题出在 prediction.label 与 trading_advice 上：本报把 label 写成了偏多的叙事（「主线由光链上游修正为存储＋CPO模组」「CPO龙头首次收复MA20完成背书」），把置信度由57%上调至60%，把仓位上沿由55%上调至60%。这三个动作没有一个是 base 情景所蕴含的——base 的条件集对方向是沉默的，而本报替它说了话。 更值得记录的是这个错误的隐蔽性：它不会被情景复盘发现。因为条件全中，机械复盘会判定「预测正确」。只有把 prediction 与 forecast_ledger 分开检验，才会发现两者说的不是同一件事。本报此前的复盘流程没有这一步。 【教训二：本报引用了多期的外围涨跌幅，其口径从未被交叉验证过】 本期在核对港股时发现：快照 ^HSI 的 chg=+1.41%，而恒指8/18的单日涨跌幅是+0.07%（E7），8/17是+1.34%（E6）——+1.41%是这两天的累计值。原因是该行 carried_forward=true 时，其 prev_close 停留在2026-08-14的收盘价上。同样的问题在日股上更严重：快照 ^N225 的 chg=-1.82%，而日经8/18实际单日跌1759日元即-2.54%（E9）。 本报此前各期都直接引用了 global_markets 的 chg 字段。playbook 的口径规则里写了 row_stale 与 carried_forward 两条，本报也照做了——但那两条管的是「价格是否陈旧」，而这次的问题是「价格正确、分母陈旧」。价格通过了所有既有检查（row_stale=false、market_date=2026-08-18、经外部核验与真实收盘一致），涨跌幅却是错的。既有的检查项之间存在这样一个缝隙，本报三期以来没有发现它，因为从来没有把 chg 与外部单日收评对过一次。 这条教训的普遍形式是：一个派生字段可以在其所有输入都通过校验的情况下仍然是错的，只要它的计算跨越了两个时点。对派生字段，校验其输入不能替代校验其本身。 顺带记录一个反例以免矫枉过正：韩股同样标着 carried_forward，但其 chg=-1.55% 与外部完全一致——因为8/17是韩国休市日，prev_close 取8/14恰好就是正确的前一交易日。所以规则不能写成「carried_forward 一律不可用」，而必须写成「carried_forward 时必须逐个市场核对」。 【教训三：一次做对的事——用自建复算去检验自己上一期写下的条件】 上一期 bear 情景的第④项条件是「23只RSI(12)≥80的个股当日均值跑输观察池均值≥1.5个百分点」。复盘时本报没有那23只的名单（上一期只记了数量）。做法是：用本次 klines_cache，按抓数脚本同一口径（12日简单移动平均）重算截至8/17的RSI(12)，结果得到RSI≥80者恰为23只、≥70者恰为34只，与上一期记录逐位一致——这同时验证了重算口径与抓数脚本一致，重算结果因此可以用来检验条件。答案是：这23只8/18均值-1.477%，观察池均值-1.422%，仅跑输0.055个百分点，条件明确不成立。 这个结果对本报是不利的（它证伪了 T-OIL-RATE-SHOCK 的一个子命题），但正因为不利才值得记录方法：当一个条件在下一期无法直接检验时，先想办法用可复现的方式重建它的输入，并用一个已知答案（数量23与34）验证重建口径，再检验条件。如果只是写「上一期名单不可得，本条 unavailable」，本报就会漏掉本期最实质的一次论点修正。
规则更新　本期新增两条规则，并修订一条既有规则。 【R17（新增）——区间型情景的叙事约束】当 forecast_ledger 中概率最高的情景，其条件集为区间型（即同一组条件能被相反方向的行情同时满足）时，prediction.label 与 trading_advice.rationale 不得作单向表述，必须同时写出区间两端的行情形态与各自的仓位含义；且 prediction.confidence 的变动方向不得由该情景的条件命中率推出——条件命中率只能支持「框架有效」，不能支持「方向正确」。配套的复盘要求：每期复盘必须把 forecast_ledger 的条件核对与 prediction 的方向核对分两次做，并在 reflection.prior_result 中分别给出结论；两者不一致时，prior_result 记为 partial 而非 correct。 【R18（新增）——派生字段必须独立于其输入被交叉验证】任何跨两个时点计算的派生字段（涨跌幅、区间收益、同比环比），在引用前必须用「本字段本身」与外部同口径来源对一次，不得因其输入字段（价格、market_date、row_stale、is_fallback）全部通过校验就默认该字段正确。具体到 global_markets：引用任一区域的 chg 之前，必须先检查该行的 carried_forward，若为 true 则必须逐个市场用 price/prev_close 反算并与该市场的外部单日收评核对（不可按区域一刀切——韩股本期即为反例，其 carried_forward 为 true 但 chg 正确）；无法核对的，只写价格与 market_date，不写涨跌幅（本期台股即按此处理）。 【R14 修订——判据的信息量下限】原R14要求判据可机械检验。本期补充：判据若在本报跟踪期内几乎恒真（或恒假），则不具备信息量，必须收紧。本期已据此把 T-INDEX-STRUCTURE-INTACT 的判据由「四大指数高于各自MA5与MA20」（跟踪期内几乎恒真）收紧为「四大指数高于各自MA20 且 观察池中低于MA20者≤8只」。下一期起，任何连续五期以上判定结果不变的判据都必须复核其信息量。
